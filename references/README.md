# References (supplemental information)

Shared cosmology source papers. This folder is **reference material**, not project source.

Copy this `references/` tree into every grok-Ramage project as the same supplemental-information set.

## Papers

### 1. TASI lectures — standard cosmology

- **File:** `TASI_Lectures - Introduction to Cosmology.pdf`
- **Authors:** Mark Trodden, Sean M. Carroll
- **Date:** 27 January 2004
- **arXiv:** [astro-ph/0401547](https://arxiv.org/abs/astro-ph/0401547)
- **What it is:** Pedagogical TASI notes on ΛCDM: Robertson–Walker metric, Friedmann equations, dark energy, CMB, BBN, baryogenesis, inflation.

### 2. Kosinov — Planck’s constant and observable-universe parameters

- **File:** `PARAMETERS OF THE OBSERVABLE UNIVERSE AND PLANCK'S CONSTANT IN ONE EQUATION a the strange and useful unity of the constants of the microcosm and the universe..pdf`
- **Author:** Mykola Kosinov
- **What it is:** Large-number identities that put \(\hbar\) in the same algebraic combinations as \(M_U\), \(\Lambda\), \(R_U\), \(G\), and electron constants. The paper states that the identities have no explanation, and proposes using the precision of \(\hbar\) and \(G\) to compute universe parameters.

## How to use these

Treat both as supplemental information:

- Trodden–Carroll is the conventional GR / ΛCDM baseline.
- Kosinov is a proposed set of micro/macro constant coincidences, not a derivation from the Friedmann equation.

They do not by themselves constitute a project result.
